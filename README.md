# 🛡️ منصة حصين للحوار المعرفي الآمن (Haseen Project)

منصة رقمية ومساعد حواري ذكي (Chatbot) يدمج بين تقنيات **الذكاء الاصطناعي التوليدي** وحصانة **الأمن السيبراني** لخدمة المحتوى الإسلامي والتعريف به، ومصمم خصيصاً للمشاركة الفردية في **تحدي باذل للذكاء الاصطناعي**.

## 🚀 مسار التحدي
* **المسار الأول:** الحوار المعرفي والإجابات الموثوقة.

## 🎯 المشكلة التي يعالجها المشروع
1. **الهلوسة البرمجية (AI Hallucination):** ميل النماذج اللغوية العامة لإعطاء إجابات غير دقيقة أو ضعيفة السند في المسائل الشرعية الحساسة.
2. **المخاطر السيبرانية وحقن الأوامر (Prompt Injection):** تعرض الأنظمة الحوارية لهجمات برمجية خبيثة تُجبر الذكاء الاصطناعي على الانحراف عن أهدافه وتقديم معلومات مشبوهة أو مغلوطة.

## ✨ الحل والمزايا التقنية
* **بنية RAG المقيدة:** ربط محرك البحث الذكي بقواعد بيانات شعاعية (Vector Databases) تحتوي حصراً على المصادر الإسلامية الرسمية والأحاديث الصحيحة لمنع توليد إجابات خارجية.
* **طبقة حماية سيبرانية (Guardrails):** خوارزمية ذكية مطورة بلغة Python لفحص مدخلات المستخدمين فوراً، وتحديد وصد هجمات حقن الأوامر وتصفيتها قبل وصولها للنموذج لضمان أمان الردود بنسبة 100%.

## 💻 المكدس التقني (Technical Stack)
* **لغة البرمجة الأساسية:** Python
* **إطار عمل الذكاء الاصطناعي:** LangChain & ChromaDB (Vector DB)
* **بيئة التطوير والتحقق:** Google Colab
* **تصميم واجهات المستخدم UI/UX:** واجهات هاتف محمول متكاملة (تصميم Figma)
